teamwfh — Message Digest Verifier Ethereum Sepolia Testnet
What is this?

Every 10 messages in a conversation, the server computes a keccak256 hash of the concatenated ciphertexts and records it on the Ethereum Sepolia blockchain. This page lets you independently verify that the messages have not been tampered with since that recording.
